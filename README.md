## Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors Game** developed using the **C programming language**. The game allows the user to play against the computer, where the computer randomly selects Rock, Paper, or Scissors and the winner is determined based on the standard game rules.

### Features

* User vs Computer gameplay
* Random computer choices
* Automatic winner determination
* Simple and easy-to-use interface
* Score tracking
* Replay option

### Technologies Used

* C Programming Language
* Standard C Libraries
* Random Number Generation

### Project Objective

The main objective of this project was to strengthen my understanding of **C programming fundamentals**, including variables, conditional statements, loops, functions, and random number generation while building a fun mini-game.
